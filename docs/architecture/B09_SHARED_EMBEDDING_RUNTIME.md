# B09 shared embedding runtime boundary

Spec: approved P0 v1.0.1 §6.6,7.4.1,10.3,TC13/20/26/32. Extends PR7; no B07/B12/B08 code copied or merged. Existing QueryEmbedder/EmbeddingBinding and pinned retriever remain the consumption contract.

ManagedQueryEmbedder owns an operational lifecycle around an injected EmbeddingBackend, with one immutable SharedEmbeddingConfig per revision. Every declared model/tokenizer/config artifact must have exact trusted size/hash and a safe relative path; the main artifact must be present. Existing B07 ArtifactIntegrityValidator checks actual bytes before any native load. The backend returns exact runtime ID and full EmbeddingBinding (dataset/model/artifact/path/dimension/tokenizer/pooling/normalization). No runtime/ABI/license/model/config is selected or approved here. Missing backend is UnavailableEmbeddingBackend, never a fake vector.

RuntimeOperationLane extracts the pre-existing ManagedModelRuntime cancellation/timeout/drainage algorithm for reuse, rather than duplicating it for embeddings. A logical interrupted result can settle while native work or its cancel remains pending; no unload/reuse is allowed until whenIdle. Failed/partial native load is recovered by successful explicit unload. A failed vector or backend operation enters error; recover by drain→unload→load. ManagedModelRuntime public behavior is preserved and its existing regression tests run unchanged. Exceptions remain typed and native detail/query text is not exposed through thrown generic errors. Embedding execution failure maps to operational Tutor RESOURCE_NOT_READY, never a scientific refusal.

Vectors are copied immutable and checked for finite values/exact dimensions. No inferred normalization, relevance threshold, tokenizer substitution, expected-vector tolerance, scientific evaluation or network request is added. Unnormalized output remains unchanged for the approved backend/index contract to determine. The caller retains its actual immutable revision/file lease until unload succeeds. This library does not invent an on-disk manifest or grant product readiness; operational ready means only this instance loaded through the supplied backend.

Direct B12→B09 provider wiring is intentionally not fabricated across unmerged branches. B09 RevisionPinnedHandle owns runtime/index/metadata; B12 RevisionPinnedHandle owns file revision/pin. Their documented adapter must compose these lifetimes after both ancestors are available in an authorized integration base, release file pin only after runtime drainage, and preserve exact historical-revision/source semantics. No copied compatibility shim or shadow DatasetProvider is installed in production. B12 recovery alone does not supply an approved index parser/runtime.
