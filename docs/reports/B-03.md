## 2. ما الذي نُفذ؟

- `lib/data/schema.drift`: المخطط المعتمد للجداول الخمسة: `user_profile`, `conversation`, `message`, `app_setting`, `installed_resource`، مع قيود FK وCHECK وUNIQUE والفهارس.
- `lib/data/app_database.dart`: Drift schema v1 مع `onCreate`, رفض ترحيل غير معرّف بدل إسقاط البيانات، وتفعيل `PRAGMA foreign_keys=ON`.
- `lib/data/app_database.g.dart`: ناتج التوليد الآلي.
- `lib/data/user_repository.dart`: حساب واحد، حماية `account_epoch` وNonce Hash وحذف الحساب.
- `lib/data/conversation_repository.dart`: معاملات أول رسالة وحد أقصى 10 محادثات، إزالة الأقدم ذريًا، منع تكرار `message_id` وRollback.
- `lib/data/settings_repository.dart`: إعدادات مرتبطة بالمستخدم و`account_epoch`.
- `lib/data/resource_repository.dart`: موارد مستقلة عن الحساب، مع منع التحول إلى READY دون مسار التحقق المناسب.
- `lib/data/database_runtime.dart`: اتصال قاعدة بيانات واحد كسول مع إغلاق آمن؛ الربط بـAppBootstrap مؤجل إلى B-04.
- `docs/notes/B-03_STEP1_AR.md`, `B-03_STEP2_AR.md`, `B-03_STEP3_AR.md`: سجلات العمل المرحلية.
- `pubspec.yaml`, `pubspec.lock`: اعتماديات SQLite/Drift والتوليد واختبار Android.

## 4. المشكلات والإصلاحات

1. **تعارض الاعتماديات:** أحدث `drift 2.35.2` مع `drift_dev` لم يتوافق مع Flutter/Dart/Meta في البيئة؛ استُخدم الزوج `drift 2.33.0` و`drift_dev 2.33.0` ونجح `flutter pub get`.
2. **فشل توليد الكود:** الخطأ `'dart compile' does not support build hooks, use 'dart build' instead`؛ نجح الحل `dart run build_runner build --force-jit` وتولدت 25 مخرجًا.
3. **غياب `.g.dart`:** أدّى لأخطاء متتابعة في Analyzer والاختبارات؛ زالت عند توليد الملف.
4. **تحذير Drift:** ظهر في اختبار إعادة الفتح. عُزل الاختبار عن تهيئة Test Database المشتركة، واختفى التحذير دون تعطيله.
5. **ملاحظات Lint:** عولجت ملاحظة الأقواس واستيراد غير لازم حتى أصبح `flutter analyze` نظيفًا.
6. **ظهور/اختفاء تطبيق اختبار Android:** دورة حياة الاختبار الآلي تتضمن إنهاء جلسة الاختبار؛ أكّد المنفذ نجاح التشغيل الطبيعي. ظهرت لاحقًا `Lost connection to device` دون دليل على انهيار التطبيق أثناء التشغيل الطبيعي.
