## 5. الملاحظات والفجوات

1. **وصف قديم في الشاشة الرئيسية:** ما زالت بطاقة المعاينة تعرض عنوان `B-02` وتذكر أن SQLite والمصادقة لم تُنفذا. العبارة أصبحت مضللة على مستوى المشروع؛ B-03 وB-04 Auth Core نُفذا فعليًا، لكنهما غير متصلين بعد بالتدفق البصري. يجب تصحيح النص عند تحديث شاشة البداية، لا حذف التحذير الخاص بكون المسار الحالي معاينة.
2. **الواجهة غير إنتاجية:** لا يوجد مسار تسجيل دخول يُمرّر `AuthSession` و`ConversationDraftController` إلى `ChatPage` عند التشغيل الاعتيادي.
3. **إعداد KDF الإنتاجي غير محسوم:** نجاح محرك Android Keystore للجلسة لا يعني اعتماد إعداد حماية كلمة المرور. لا يجوز استخدام معلمات اختبار منخفضة في الإنتاج.
4. **وظائف Tutor والرسائل التالية:** إدخال السؤال الثاني، وعرض الإجابة المسندة بالمصادر، والتكامل مع Local LLM/RAG ما زالت خارج هذا الجزء.
5. **ملفات محلية غير متتبعة:** سجلات ANR/Logcat وملاحظات B-04 وتجاربها، وكذلك تغييرات `AndroidManifest.xml` و`res/xml`، ليست ضمن Commit B-05؛ لا ينبغي رفع ملفات السجلات إلى GitHub.

## 6. القرار والتسليم

**قرار هذه الخطوة:** GO للانتقال إلى ربط بدء تشغيل التطبيق ببوابة حساب/جلسة صحيحة، ثم إعادة اختبار الحفظ الحقيقي على الهاتف. **ليس GO للإصدار الإنتاجي**، وليس اعتمادًا لـKDF أو Tutor.

**الخطوات التالية ذات الأولوية:**

1. تحديث رسائل الواجهة القديمة حتى تعكس بدقة ما بُني وما لا يزال غير موصول.
2. إعداد مسار Bootstrap يميز بين: لا حساب محلي، حساب موجود بلا جلسة، وجلسة صحيحة؛ مع الفشل الآمن وعدم إنشاء جلسة تلقائيًا دون تحقق.
3. إكمال شاشات إنشاء الحساب/تسجيل الدخول عبر إعداد KDF معتمد أمنيًا قبل السماح باستخدامها إنتاجيًا.
4. اختبار فعلي متكامل: فتح محادثة جديدة لا ينشئ سجلًا؛ أول سؤال صالح ينشئ سجلًا واحدًا؛ حد 10 محادثات يعمل عند تجاوزه؛ إعادة فتح التطبيق تعيد الجلسة الصحيحة.
5. حفظ التقريرين في `docs/reports/` ثم Commit توثيق مستقل إذا وافق فريق التنفيذ؛ لا يُذكر رقم Commit للتوثيق قبل إنشائه.
